
  # Park Easy — Smart Parking On The Go 🚗

A smart parking project focused on exploring how a digital solution can make the parking experience simpler and more convenient for users.

## 📌 About the Project

Finding convenient parking can be frustrating, especially in busy areas. **Park Easy** is a project built around the idea of improving this experience through a user-friendly digital interface.

The project focuses on designing a potential smart parking solution and exploring how technology and thoughtful user experience design can address everyday parking challenges.

## 🎯 Project Objectives

- Explore a digital solution to common parking challenges.
- Design a simple and user-friendly interface.
- Understand user needs and organize the experience around them.
- Apply UI/UX principles to a real-world problem.
- Explore how a digital parking solution could be developed further.

## 🛠️ Tech Stack

- React
- TypeScript / TSX
- Vite
- CSS

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js and npm installed on your system.
- Git installed on your system.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/palakk13/Park-Easy.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Park-Easy
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal to view the application.
